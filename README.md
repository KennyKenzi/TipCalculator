# Tip Calculator

A simple tip calculator built while learning React.

This is one of my earlier React projects. I'm keeping it here as part of my learning journey and to show some of the technologies I was exploring at the time. The code and UI reflect my experience level when it was created and may contain areas that could be improved.

## Run Project

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm start
```

Open:

```text
http://localhost:3000
```

in your browser.
